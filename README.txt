Shopfront — free Bootstrap 5 e-commerce template by uiCookies
============================================================

Concept
-------
"Ember" is a modern sneaker & apparel boutique. The idea was to make an online
store that feels like a real fashion brand rather than a stock template grid:
confident display type, a warm neutral canvas, one energetic brand colour and a
single hot accent reserved only for sale urgency. It ships as two pages — a
long-scroll storefront (index.html) and a genuine product-detail page
(product.html) with a working gallery, variant pickers, quantity stepper and
detail/review tabs — all in vanilla JavaScript, no jQuery, no icon fonts, no CDN.

Palette
-------
Ink        #17181D  (cool near-black — text, header, footer)
Bone paper #FAF9F6  (bright page canvas)
Sand       #ECE6DA  (warm section / tile background)
Cobalt     #2743E6  (primary brand accent, CTAs, links, cart)
Cobalt deep#1B31B5  (hover state)
Flare      #FF5636  (flame-orange — used ONLY for sale prices, badges & urgency)
Line       #E3DED4  (hairline borders)

Cobalt against flame-orange is a deliberately energetic retail pairing — it
avoids the usual cream+serif+terracotta and acid-green-on-black clichés.

Type pairing
------------
Display : Bricolage Grotesque (700 / 800) — characterful modern grotesque
Body    : DM Sans (400–600) — clean, friendly, highly legible
Labels  : DM Mono (400 / 500) — eyebrows, prices, badges & SKUs for a retail-spec feel

Fonts load from Google Fonts. Bootstrap 5 is self-hosted in css/vendor & js/vendor.
All icons are hand-written inline SVG. © 2026.
